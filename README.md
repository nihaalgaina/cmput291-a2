## How to run tests locally on lab machines

1. Download the testing script and public databases from Google Drive linked on Canvas
2. Copy the tests.tar.gz file to the root directory here
3. Run `tar -xvzf tests.tar.gz`
4. Run `bash ./tests/start.sh`

> [!NOTE]
> Running queries directly in the db files manually may cause the tests to fail.
> Re-run the tar command to reset them.
